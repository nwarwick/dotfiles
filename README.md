# Dotfiles

Personal dotfiles split into independent platform trees. Changes under one
platform do not affect the other.

| Platform | Setup | Details |
|---|---|---|
| macOS | `./mac/setup-macos.sh` | [mac/README.md](mac/README.md) |
| Omarchy / Arch Linux | `./linux/setup-linux.sh` | [linux/README.md](linux/README.md) |

The macOS tree is a fresh baseline from the current Mac and uses plain Zsh.
The Linux tree preserves the existing Omarchy configuration and behavior.
